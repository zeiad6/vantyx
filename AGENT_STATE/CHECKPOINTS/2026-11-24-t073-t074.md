## Work

1. Added `src/lint.rs`, a read-only AST pass:
   - `L0001`: local or global binding never read.
   - `L0002`: `var` read but never written after declaration.
   - `L0003`: first statement after a direct `return`/`break`/`continue` in a
     block.
   Names starting with `_`, parameters, loop variables, and match bindings are
   ignored. Plain assignment is a write; compound assignment reads and writes.
   Imported modules are linted through the flattened checked program.
2. Added `vantyx lint <file>`:
   - compiles with the normal pipeline first;
   - prints warnings with source spans;
   - exits `0` for lint-only findings and `1` for compile errors;
   - accepts `-` for standard input;
   - `run`, `check`, and `build` do not emit lint warnings.
3. Fixed `src/checker.rs::block_returns`:
   - the old version inspected only the last statement, so dead code after
     `return` caused a false `E0309`;
   - the new version walks reachable statements, stops at the first
     `return`/`break`/`continue`, and treats a fully returning `if` with `else`
     or `match` as terminating.
4. Added documentation:
   - `docs/linting.md`;
   - `docs/decisions/ADR-0037-static-lints.md`;
   - specification §14;
   - README, status, baseline, task, and agent-state synchronization.
