## T-091 result

`vantyx ai inspect` now accepts a Safetensors shard index
(`*.safetensors.index.json`) in addition to GGUF v2/v3 and single Safetensors
files.

Implemented in `src/ai/model.rs`:

- `ModelFormat::SafetensorsIndex` (`"safetensors-index"`), `ShardSummary`, and a
  `shards` array on `ModelSummary` and its JSON output.
- Index detection when the 8-byte prefix is not a plausible Safetensors header
  length and either the first non-whitespace byte is `{` or the path ends in
  `.json`. A shard that is itself an index is rejected, so indexes cannot
  recurse.
- Bounded parse: 64 MiB index JSON, 10,000 shards, 1,000,000 tensors, and the
  existing 10,000-entry Safetensors metadata cap.
- Shard paths must be relative, use `/`, contain no `..`, end in
  `.safetensors`, and stay under the canonical index directory after symlink
  resolution.
- Every shard is validated with the T-090 Safetensors parser. Each shard header
  is re-read to cross-check names: extra shard tensors, indexed tensors missing
  from their shard, and tensors in more than one shard are format errors.
- Aggregation of tensor count, parameter count, data bytes, and dtype
  histogram, with checked arithmetic. The summary digest covers the index JSON;
  each `ShardSummary` carries the shard's size, digest, tensor count, parameter
  count, and data bytes.
- `metadata.total_size` mismatch or non-integer value is a warning, not a
  rejection.
- Metadata projection from index metadata (`architecture`, `name`,
  `context_length`, `embedding_length`/`hidden_size`, `block_count`/
  `num_hidden_layers`, `quantization`, tokenizer fields).

Other files:

- `src/ai/mod.rs` exports `ShardSummary`.
- `src/ai_cli.rs` prints a `shards:` list and updates the inspect usage/help.
- `tests/ai.rs::inspect_aggregates_safetensors_shards` covers text, JSON, and

## Scope limits

- Shard validation is best-effort and not atomic; a shard can change between
  its digest and its header check, and a symlink can be retargeted
  concurrently.
- The inspector does not scan for unlisted shards, compare against a remote
  repository, download missing shards, verify licenses, or validate tensor
  values.
- `metadata.total_size` is advisory.
- Each shard header is read twice: once by the validator and once for the name
  cross-check.
- GGUF remains single-file; no download, pull, remove, conversion,
  quantization, or weight loading was added.
