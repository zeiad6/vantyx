## Objective

Add `remove(map: Map[K, V], key: K) -> Bool`, which deletes the first entry
whose key is structurally equal to `key`, preserves the insertion order of the
remaining entries, and reports whether an entry was removed. Missing keys
return `false` and leave the map unchanged. Both engines must agree on output,
exit code, aliases, and argument evaluation order.

## Files changed

- `src/checker.rs`: registers `remove`; checks the map and key types; passes the
  map key type as the key argument's expected type so a direct empty list
  literal can adopt `List[T]`; `E0301` for non-maps and mismatched keys,
  `E0302` for wrong arity.
- `src/interp.rs`: finds the first structurally equal entry in the
  insertion-ordered vector, removes it, and returns `Bool`.
- `src/ir.rs`: validates a native `Map` and a key assignable to the map key
  type.
- `src/codegen_c.rs`: binds the map and key in source order; adds
  `vantyx_map_remove`, which left-shifts the entry buffers with `memmove`,
  decrements the length, and rebuilds the scalar-key hash index. Native
  `ForMap` now snapshots the keys with `vantyx_map_keys` at loop start, so
  removal during iteration does not skip later keys, matching the
  interpreter's key snapshot.
- `tools/differential_fuzz.py`: the control-flow shape removes each visited
  map key during iteration, exercising the snapshot path across seeds.
- `tests/e2e.rs`: five tests for removal/order/aliases/equality, scalar and
  structural keys including a 500-entry map, removal during iteration, the
  `E0301`/`E0302` static checks, and the `R0005` dynamic non-map error.
- `tests/native.rs`: one differential test including key-expression evaluation
  order, aliases, structural keys, `-0.0`/`0.0`, repeated removal, and removal
  during iteration, plus an `E0401` test for a dynamically typed map.
- `docs/language_specification.md`, `README.md`, `TASKS.md`,
  `PROJECT_STATUS.md`, and the agent-state files.

## Scope limits

- One map and one key; no bulk, predicate, or clear operations.
- Removed keys and values are not reclaimed in v0.1; the map's buffers do not
  shrink.
- Scalar-key removal rebuilds the hash index in O(n); structural-key removal
  remains linear.
