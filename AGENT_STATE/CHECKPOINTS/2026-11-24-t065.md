# Checkpoint — 2026-11-24 — T-065 lexical glob expansion

## Objective

Add zero-dependency lexical glob expansion to the interpreter and native
backend with matching grammar, hidden-entry and symbolic-link rules, ordering,
limits, and error codes: `glob(pattern: Str) -> List[Str]`.

## Contract (ADR-0033)

- Patterns split on `/`; empty components are discarded; a leading `/` makes
  the pattern absolute. `/` and `//` expand to `/`. An empty pattern is
  `R0016`.
- `*` matches zero or more Unicode scalar values in a component, `?` matches
  one, and `[abc]`/`[a-z]`/`[!a-z]` classes match scalar values. `]` first in a
  class and `-` first or last are literal. Unclosed/empty classes and
  descending ranges are `R0016`.
- Only a whole-component `**` is special. It matches zero or more directory
  levels and descends only through real directories, never symbolic links. A
  final `**` returns non-hidden descendants but not the base.
- Wildcards and `**` skip names beginning with `.` unless the component starts
  with a literal `.` or a positive class containing `.`.
- Results are lexical spellings, byte-sorted and deduplicated. A final literal
  is probed with `lstat`, so dangling links are returned; any final `lstat`
  failure is no match. Missing paths and non-directories produce no matches.
- Listing or `**` `lstat` failures, non-UTF-8 entry names, more than 100,000
  candidate paths before deduplication, and `**` depth beyond 128 are `R0015`.
  More than 1,024 components is `R0016`.
- Static non-`Str` arguments are `E0301`; dynamic interpreter values are
  `R0005`; dynamically typed native patterns are `E0401`. The interpreter
  rejects NUL patterns with `R0015`; native NUL source is already `E0401`.
- No escaping, brace/tilde/variable expansion, case folding, normalization,
  `..` confinement, sandbox, streaming, or filesystem mutation.

## Implementation

- `src/glob.rs`: parser, Unicode component matcher, hidden rules, literal
  probes, symlink-safe `**` walk, sorting/deduplication, caps, and unit tests.
- `src/lib.rs`: module registration.
- `src/checker.rs`: builtin registry, arity, `E0301` pattern check, `List[Str]`.
- `src/interp.rs`: dispatch, `R0005`/`R0015`/`R0016` mapping.
- `src/ir.rs`: native `Str` validation and `List[Str]` lowering.
- `src/codegen_c.rs`: `vantyx_glob` and POSIX `opendir`/`readdir`/`lstat`
  helpers with matching grammar, hidden/symlink rules, sorting, deduplication,
  and caps.
