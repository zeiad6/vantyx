## T-092 result

`vantyx ai dataset <file> [--json]` validates a UTF-8 JSONL corpus without
loading it whole.

Implemented in `src/ai/dataset.rs`:

- `DatasetSummary`, `FieldSummary`, `TypeCount`, `InvalidLine`, and
  `inspect_dataset`, plus a bounded line reader that hashes every byte while
  consuming oversized lines without buffering them.
- One top-level JSON object per non-blank line. A first-line BOM, CRLF, and
  blank lines are accepted; invalid JSON, invalid UTF-8, and non-object records
  are counted and the first 20 are reported with line numbers and messages.
- The summary reports path, format, byte size, SHA-256, line/blank/record/
  invalid counts, sorted top-level fields with record counts and JSON type
  histograms, and warnings. `--json` emits a stable object.
- Limits: 256 MiB per file, 16 MiB per line, 10,000 distinct top-level fields,
  20 reported invalid lines.
- Exit semantics: valid dataset `0`; invalid content or I/O `1` with the
  summary printed first; usage `64`.
- `src/ai/mod.rs` exports the API; `src/ai_cli.rs` adds the command and usage
  text. `docs/ai/DATASET_INSPECTION.md`, ADR-0043, the README AI section,
  `examples/ai/README.md`, and `examples/ai/train.jsonl` document and exercise
  it. Nothing is downloaded, executed, or modified.
